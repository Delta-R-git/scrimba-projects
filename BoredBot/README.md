## 📝 About

A simple and interactive web application built while learning web development. When you don't know what to do, BoredBot fetches a random activity suggestion to help you out!

* **API Integration:** Uses the Fetch API to pull live activity data.
* **Dynamic UI:** Updates the text, background gradient, and bot persona ("BoredBot" ➡️ "HappyBot") when an activity is generated.
* **Responsive Styling:** Clean layout styled with CSS gradients and Google Fonts.

## 📝 About

* A clean, responsive front-end landing page template displaying science, technology, and environmental articles. Built as a hands-on learning project to master modern CSS layouts.
* Advanced CSS Grid: Uses responsive grid template areas that adapt seamlessly from single-column mobile layouts to complex multi-column desktop views.

## 📂 How to Run Locally

```bash
# Clone the repository
git clone [https://delta-r-git.github.io/scrimba-projects/SciStream.git](https://delta-r-git.github.io/scrimba-projects/SciStream.git)

# Navigate to the project directory
cd scrimba-projects/SciStream

# Open index.html in your default browser
open index.html
```

## 📝 About

My Learning Journal is a clean, fully responsive personal blog website built to practice and showcase frontend development skills.

* **Multi-page Layout:** Includes a Home page, individual Blog post views, and an About Me section.
* **Modern CSS Grid & Flexbox:** Fully responsive layout that adapts seamlessly across mobile, tablet, and desktop screens.
* **Custom Typography & Styling:** Styled with Google Fonts (Roboto and Source Sans 3) and custom hover states.
